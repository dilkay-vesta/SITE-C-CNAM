# Site du BDE C'CNAM Strasbourg

Site vitrine de C'CNAM Strasbourg : accueil, événements, galerie photos, partenaires, équipe, contact et adhésion.

## Modifier le contenu (sans coder)

1. Va sur https://app.pagescms.org et connecte-toi avec ton compte GitHub.
2. Ouvre le dépôt `site-c-cnam`.
3. Choisis la rubrique à modifier dans le menu : Événements, Galerie photos, Partenaires, Équipe ou Textes et infos du site.
4. Ajoute ou modifie ce que tu veux, puis clique sur **Save**. Le site se met à jour tout seul en une à deux minutes.

Pour donner l'accès à un autre membre du bureau : ajoute-le comme collaborateur du dépôt sur GitHub (Settings > Collaborators), ou invite-le par e-mail depuis Pages CMS (Settings > Collaborators).

## Où est quoi

- `content/` : tout le contenu du site (textes, événements, partenaires, équipe, galerie).
- `images/` : logo, photos et logos des partenaires.
- `index.html`, `assets/` : la structure et le design du site. Pas besoin d'y toucher pour mettre à jour le contenu.
- `.pages.yml` : la configuration de l'espace d'administration.
